Sharing links give you a lightweight way to grant access to a collection or document without adding someone as a workspace member or managing role assignments. You generate a link and send it — the recipient clicks it and gets in, no Whisker account required. This is especially useful for one-off sharing with clients, reviewers, or anyone outside your organization.

## Shareable Links

You can generate a shareable link for any collection or document directly from the Whisker UI.

<Steps>
  <Step title="Open the collection or document">
    Navigate to the resource you want to share.
  </Step>
  <Step title="Open the Share menu">
    Click the **Share** button in the top-right toolbar.
  </Step>
  <Step title="Configure link access">
    Choose your access level (see options below) and set any additional options such as a password or expiry date.
  </Step>
  <Step title="Copy the link">
    Click **Copy Link**. The link is now active and ready to send.
  </Step>
</Steps>

All shareable links provide **read-only** access by default. Recipients can view and download content but cannot edit or delete anything.

## Link Access Options

When creating a shareable link, you can choose from three access levels:

- **Public** — Anyone with the link can access the resource immediately, with no additional authentication required.
- **Password-protected link** — Recipients must enter a password before viewing the resource. The password is separate from any collection-level password protection you may have set.
- **Expiring link** — Set an expiry date and time. After the link expires, it becomes inactive and recipients will see an access-denied message. You can extend or revoke the link at any time before it expires.

You can combine options — for example, a password-protected link that also expires on a specific date.

## Managing Share Settings via API

Use `PUT /permissions/{resource_id}` to configure share link access for a collection or document programmatically. Set `"link_sharing"` to `"public"` to generate an open link, or include a `"link_password"` and `"link_expires_at"` to add further restrictions.

**Enable a public share link:**

```http
PUT /api/v1/permissions/doc_abc123
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "link_sharing": "public"
}
```

```json
{
  "resource_id": "doc_abc123",
  "link_sharing": "public",
  "share_url": "https://app.whisker.io/share/lnk_def456",
  "link_expires_at": null
}
```

**Enable a password-protected, expiring share link:**

```http
PUT /api/v1/permissions/doc_abc123
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "link_sharing": "password",
  "link_password": "review-2025",
  "link_expires_at": "2025-12-31T23:59:59Z"
}
```

```json
{
  "resource_id": "doc_abc123",
  "link_sharing": "password",
  "share_url": "https://app.whisker.io/share/lnk_def456",
  "link_expires_at": "2025-12-31T23:59:59Z"
}
```

Replace `doc_abc123` with your document ID, or use a collection ID (e.g., `col_abc123`) to share an entire collection.

## Revoking a Share Link

**From the UI:**

Open the **Share** menu on the collection or document, find the active link, and click **Revoke**. The link is deactivated immediately.

**Via the API:**

Disable sharing entirely by setting `"link_sharing"` to `"disabled"`:

```http
PUT /api/v1/permissions/doc_abc123
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "link_sharing": "disabled"
}
```

```json
{
  "resource_id": "doc_abc123",
  "link_sharing": "disabled",
  "share_url": null
}
```

Once revoked, any previously shared link becomes inactive immediately. You will need to re-enable sharing to generate a new link.

## Viewing Current Share Settings

To check whether sharing is currently enabled on a resource and retrieve the active share URL, use `GET /permissions/{resource_id}`:

```http
GET /api/v1/permissions/doc_abc123
Authorization: Bearer YOUR_API_KEY
```

```json
{
  "resource_id": "doc_abc123",
  "link_sharing": "public",
  "share_url": "https://app.whisker.io/share/lnk_def456",
  "link_expires_at": null,
  "password_protected": false,
  "members": []
}
```

<Note>
  Share links are designed for human recipients. If you need an AI agent to
  programmatically access a collection or document, use an **agent token**
  instead. Agent tokens support scoped, long-lived access and are the correct
  mechanism for machine-to-machine access. See [Connecting Agents](/agents/connecting-agents)
  for more details.
</Note>
