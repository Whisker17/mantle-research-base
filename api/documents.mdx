---

Documents are the core content unit in Whisker. Each document belongs to a collection and can contain Markdown, HTML, or plain text. The Documents API lets you create, retrieve, update, delete, and search documents programmatically — including uploading files directly. All endpoints require a valid API key or agent token with appropriate access.

---

## GET /documents

List all documents accessible to the caller. Results are paginated and can be filtered by collection or a search query.

```http
GET /v1/documents?collection_id=col_01hx9z&page=1&per_page=20
Authorization: Bearer wsk_live_your_api_key_here
```

**Query Parameters**

<ParamField query="collection_id" type="string">
  Filter results to documents within a specific collection.
</ParamField>

<ParamField query="search" type="string">
  Full-text search query. Matches against document titles and content.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number to retrieve.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  Number of documents per page. Maximum is 100.
</ParamField>

**Response**

```json
{
  "data": [
    {
      "id": "doc_01ab3f",
      "title": "Q3 Research Report",
      "collection_id": "col_01hx9z",
      "format": "markdown",
      "created_at": "2024-11-01T12:00:00Z",
      "updated_at": "2024-11-05T09:30:00Z"
    }
  ],
  "meta": {
    "total": 42,
    "page": 1,
    "per_page": 20
  }
}
```

<ResponseField name="data" type="array">
  Array of document objects.

  <ResponseField name="id" type="string">
    Unique document identifier.
  </ResponseField>

  <ResponseField name="title" type="string">
    Document title.
  </ResponseField>

  <ResponseField name="collection_id" type="string">
    ID of the collection this document belongs to.
  </ResponseField>

  <ResponseField name="format" type="string">
    Content format: `markdown`, `html`, or `plain`.
  </ResponseField>

  <ResponseField name="created_at" type="string">
    ISO 8601 timestamp of when the document was created.
  </ResponseField>

  <ResponseField name="updated_at" type="string">
    ISO 8601 timestamp of the last update.
  </ResponseField>
</ResponseField>

## POST /documents

Create a new document inside a collection.

```http
POST /v1/documents
Authorization: Bearer wsk_live_your_api_key_here
Content-Type: application/json

{
  "title": "Competitive Analysis — Q4",
  "content": "## Overview\n\nThis document covers...",
  "collection_id": "col_01hx9z",
  "format": "markdown"
}
```

**Body Parameters**

<ParamField body="title" type="string" required>
  The document title. Must be between 1 and 255 characters.
</ParamField>

<ParamField body="collection_id" type="string" required>
  The ID of the collection to place this document in. You must have write access to the collection.
</ParamField>

<ParamField body="content" type="string">
  The document body. Interpreted according to the `format` field.
</ParamField>

<ParamField body="format" type="string" default="markdown">
  Content format. Accepted values: `markdown`, `html`, `plain`.
</ParamField>

**Response** — `201 Created`

```json
{
  "data": {
    "id": "doc_07xq2m",
    "title": "Competitive Analysis — Q4",
    "collection_id": "col_01hx9z",
    "format": "markdown",
    "content": "## Overview\n\nThis document covers...",
    "created_at": "2024-11-10T14:22:00Z",
    "updated_at": "2024-11-10T14:22:00Z"
  }
}
```

## GET /documents/{id}

Retrieve a single document by its ID, including full content.

```http
GET /v1/documents/doc_07xq2m
Authorization: Bearer wsk_live_your_api_key_here
```

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique ID of the document to retrieve.
</ParamField>

**Response**

```json
{
  "data": {
    "id": "doc_07xq2m",
    "title": "Competitive Analysis — Q4",
    "collection_id": "col_01hx9z",
    "format": "markdown",
    "content": "## Overview\n\nThis document covers...",
    "created_at": "2024-11-10T14:22:00Z",
    "updated_at": "2024-11-10T14:22:00Z"
  }
}
```

<ResponseField name="data.content" type="string">
  The full document body. Only included in single-document responses, not list responses.
</ResponseField>

## PUT /documents/{id}

Update an existing document's title, content, or collection. Only include the fields you want to change — omitted fields are left unchanged.

```http
PUT /v1/documents/doc_07xq2m
Authorization: Bearer wsk_live_your_api_key_here
Content-Type: application/json

{
  "title": "Competitive Analysis — Q4 (Final)",
  "content": "## Overview\n\nUpdated content here..."
}
```

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique ID of the document to update.
</ParamField>

**Body Parameters**

<ParamField body="title" type="string">
  New document title.
</ParamField>

<ParamField body="content" type="string">
  New document body.
</ParamField>

<ParamField body="collection_id" type="string">
  Move the document to a different collection. You must have write access to the target collection.
</ParamField>

**Response**

```json
{
  "data": {
    "id": "doc_07xq2m",
    "title": "Competitive Analysis — Q4 (Final)",
    "collection_id": "col_01hx9z",
    "format": "markdown",
    "content": "## Overview\n\nUpdated content here...",
    "created_at": "2024-11-10T14:22:00Z",
    "updated_at": "2024-11-11T08:05:00Z"
  }
}
```

## DELETE /documents/{id}

Permanently delete a document. This action cannot be undone.

```http
DELETE /v1/documents/doc_07xq2m
Authorization: Bearer wsk_live_your_api_key_here
```

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique ID of the document to delete.
</ParamField>

**Response** — `204 No Content`

An empty response body is returned on success.

<Warning>
  Deleting a document is permanent. Whisker does not maintain a trash or recovery mechanism for deleted documents.
</Warning>

## POST /documents/upload

Upload a file to create a document. The file is parsed and processed asynchronously — the response returns immediately with a `status: processing` flag.

```http
POST /v1/documents/upload
Authorization: Bearer wsk_live_your_api_key_here
Content-Type: multipart/form-data

file=@report.pdf
collection_id=col_01hx9z
title=Annual Research Report 2024
```

**Form Parameters**

<ParamField body="file" type="file" required>
  The file to upload. Accepted formats: `.pdf`, `.docx`, `.txt`, `.md`, `.html`. Maximum file size is 25 MB.
</ParamField>

<ParamField body="collection_id" type="string" required>
  The ID of the collection to upload the document into.
</ParamField>

<ParamField body="title" type="string">
  A display title for the document. Defaults to the uploaded filename if omitted.
</ParamField>

**Response** — `202 Accepted`

```json
{
  "data": {
    "id": "doc_09zr4k",
    "title": "Annual Research Report 2024",
    "collection_id": "col_01hx9z",
    "format": "plain",
    "status": "processing",
    "created_at": "2024-11-11T09:00:00Z",
    "updated_at": "2024-11-11T09:00:00Z"
  }
}
```

<ResponseField name="data.status" type="string">
  Processing state of the uploaded document. Will be `processing` immediately after upload, and transitions to `ready` once parsing is complete.
</ResponseField>

<Note>
  Poll `GET /documents/{id}` to check when the document's `status` changes from `processing` to `ready` before attempting to read its content.
</Note>
