Your account settings let you control how you appear to teammates, how you authenticate, and how external tools connect to Whisker on your behalf. Access all of these options by clicking your avatar in the bottom-left corner and selecting **Settings**.

## Profile Settings

Your profile is how other workspace members identify you across Whisker. To update it, navigate to **Settings > Profile**.

- **Display name** — Enter the name you want teammates to see next to your contributions.
- **Email address** — Update the email associated with your account. You will receive a verification link at the new address before the change takes effect.
- **Avatar** — Upload a profile photo (PNG or JPG, up to 2 MB) or remove your current one to fall back to your initials.

Click **Save Changes** when you're done.

## Changing Your Password

<Steps>
  <Step title="Open Security Settings">
    Go to **Settings > Security**.
  </Step>
  <Step title="Enter your current password">
    Type your existing password in the **Current password** field to confirm your identity.
  </Step>
  <Step title="Set a new password">
    Enter your new password and confirm it in the **Confirm new password** field. Passwords must be at least 12 characters long.
  </Step>
  <Step title="Save">
    Click **Update Password**. You will be prompted to log in again on other active sessions.
  </Step>
</Steps>

## Two-Factor Authentication

Two-factor authentication (2FA) adds a second layer of protection to your account. After entering your password, you'll be asked for a time-based one-time code generated by an authenticator app.

Whisker supports any TOTP-compatible authenticator app, including:
- [Authy](https://authy.com)
- Google Authenticator
- 1Password
- Apple Passwords

**To enable 2FA:**

<Steps>
  <Step title="Go to Settings > Security">
    Scroll to the **Two-Factor Authentication** section and click **Enable 2FA**.
  </Step>
  <Step title="Scan the QR code">
    Open your authenticator app, tap **Add account**, and scan the QR code displayed in Whisker.
  </Step>
  <Step title="Enter the verification code">
    Type the 6-digit code from your authenticator app to confirm the setup.
  </Step>
  <Step title="Save your backup codes">
    Copy or download your one-time backup codes and store them somewhere safe. These let you recover access if you lose your device.
  </Step>
</Steps>

To disable 2FA, return to **Settings > Security** and click **Disable 2FA**. You will need to enter your current password to confirm.

## API Keys

Personal API keys allow you — and the tools or agents you authorize — to authenticate with the Whisker API on your behalf. Each key inherits your account's permissions within the workspace.

**To generate a new API key:**

<Steps>
  <Step title="Navigate to API Keys">
    Go to **Settings > API Keys**.
  </Step>
  <Step title="Create a new key">
    Click **Generate New Key**.
  </Step>
  <Step title="Name and configure the key">
    Give the key a descriptive name (for example, `notion-sync-bot` or `local-dev`). Optionally, set an expiration date after which the key will automatically stop working.
  </Step>
  <Step title="Copy the key">
    Your new API key is displayed **once only**. Copy it immediately and store it in a secure location such as a password manager or secrets vault.
  </Step>
</Steps>

<Warning>
  Treat your API keys like passwords. Anyone who holds a key can access Whisker as you. Never commit keys to source control, paste them into chat, or share them in plain text. If a key is ever exposed, revoke it immediately.
</Warning>

## Revoking API Keys

You should revoke API keys that are no longer in use, have been accidentally exposed, or belong to an integration you've disconnected.

<Steps>
  <Step title="Go to Settings > API Keys">
    You'll see a list of all your active keys, along with their names, creation dates, and last-used timestamps.
  </Step>
  <Step title="Find the key to revoke">
    Locate the key you want to remove.
  </Step>
  <Step title="Revoke the key">
    Click the **Revoke** button next to the key and confirm the action in the dialog. The key is invalidated immediately — any requests using it will return a `401 Unauthorized` error.
  </Step>
</Steps>

<Tip>
  Create a separate API key for each integration or service that connects to Whisker. This way, if one key is compromised or an integration is removed, you can revoke just that key without disrupting everything else.
</Tip>
